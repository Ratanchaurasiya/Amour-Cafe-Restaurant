# Amour Cafe & Restaurant - Tarkulwa, Deoria

Welcome to the official web portal for **Amour Cafe & Restaurant**, the premier fine-dining establishment and couple/family private dining cabin sanctuary located near Power House on Balpur Road, Tarkulwa, Deoria, Uttar Pradesh.

## 🌟 Highlights & Features
- **Ambient Hero Video Integration**: Crystal-clear, vibrant background video capturing authentic dining & private cabin atmospheres.
- **Pure Luxury White Aesthetic**: Custom color palette blending crisp ivory white, soft champagne, and imperial gold accents.
- **Mobile-First Responsive Design**: 
  - Ultra-clean 2-column mobile experience cards.
  - Interactive sticky bottom quick-action bar (Call, WhatsApp, Cabin Booking, Directions).
  - High-performance typography and zero-header overlap.
- **AOS & Keyframe Micro-Interactions**: Scroll-triggered reveal animations, gold button shimmer, and organic badge floating motion.
- **WhatsApp Concierge & Reservations**: Direct cabin & event booking integration via WhatsApp API.
- **Interactive Map & Local SEO**: Verified coordinates (`26.6375° N, 83.8974° E`) and Schema.org `Restaurant` JSON-LD structured data.

## 🚀 Local Development
To launch and view locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
